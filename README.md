# أَثَر — مكتبتك الشخصية
تطبيق ويب عربي RTL لإدارة مكتبة PDF وقراءة الكتب محليًا.

## التشغيل
- ارفع محتويات المجلد إلى استضافة صفحات ثابتة تدعم HTTPS (مثل GitHub Pages أو Netlify).
- افتح الرابط في متصفح حديث. يمكن تثبيته كتطبيق من قائمة المتصفح.
- قارئ PDF يحتاج تحميل PDF.js من CDN عند أول استخدام؛ لذلك يلزم اتصال بالإنترنت لتحميل المكتبة، ثم قد يعمل بعد تخزينها مؤقتًا بحسب المتصفح.

## الخصوصية والبيانات
- ملفات PDF محفوظة في IndexedDB على نفس المتصفح والجهاز.
- لا يوجد خادم ولا حساب مستخدم ولا رفع للكتب.
- لا تمسح بيانات الموقع أو المتصفح قبل تصدير نسخة احتياطية.
- النسخة الاحتياطية الكاملة بصيغة JSON تتضمن بيانات الكتب والملاحظات والعلامات وملفات PDF المشفرة داخل الملف. قد يصبح الملف كبيرًا إذا كانت المكتبة كبيرة. الاستعادة تقبل النسخ القديمة أيضًا، لكنها لا تستطيع استرجاع ملفات PDF التي لم تكن مضمنة فيها.

## الميزات
- استيراد عدة ملفات PDF، البحث، التصفية، المفضلة.
- قارئ PDF.js مع تغيير الصفحة والتكبير وحفظ آخر صفحة والتقدم.
- ملاحظات وعلامات مرجعية وتحديد الكتاب كمكتمل.
- إحصائيات وهدف سنوي.
- تصدير واستعادة بيانات المكتبة.
- PWA وواجهة متجاوبة.

## ملاحظات الإصدار
الإصدار 1.2: نسخة احتياطية كاملة تتضمن ملفات PDF، مع دعم استعادة النسخ السابقة. يدعم البحث النصي داخل صفحات PDF التي تحتوي على نص قابل للاستخراج؛ ملفات الصور الممسوحة ضوئيًا تحتاج OCR غير مدمج. لا توجد مزامنة بين الأجهزة. دعم التثبيت والعمل دون اتصال يختلف حسب المتصفح والاستضافة.
